# Troubleshooting Access to a Shared Network Folder

Confirm that you are connected to the corporate network or VPN as required and are using the correct published folder path. Sign out and back in if access was recently approved. Check whether colleagues with the same role can access the folder. If new access is needed, submit the approved access request with the folder name, business reason, and required access level. Include the exact access-denied message in an incident ticket if previously working access stops. Never use another person's credentials or move restricted files to personal storage.
