# Requesting Installation of Approved Software

Open the approved IT service portal and search the software catalogue first. If the application is unavailable, select the software request form and provide the application name, business purpose, device name, required version if known, and whether the request is for one user or a team. The request may require manager approval, licence checks, or security review. Do not download installers from unofficial websites or use personal administrator credentials. If already-installed software is broken, raise an incident rather than a new installation request.
