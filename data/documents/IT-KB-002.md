# Troubleshooting Outlook Not Opening or Synchronising

If Outlook does not open, close any visible windows, check whether it is still running in Task Manager, restart the computer, and try again. If mail is not synchronising, confirm internet access, ensure Work Offline is disabled, and run Send/Receive. Check whether the mailbox is full. Try the organisation-approved webmail service to determine whether the issue is limited to the desktop application. Include the error, device name, and whether webmail works in your support ticket. Do not delete mail data files or recreate profiles unless IT instructs you to.
