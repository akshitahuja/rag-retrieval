# Clearing Browser Cache for a Web Application Issue

Confirm the internet connection is stable and identify the affected browser and web application. Open browser privacy or history settings and clear cached images and files for a limited recent period. Avoid clearing saved passwords or autofill data. Close and reopen the browser, sign in through the normal company route, and retry. If the issue continues, test another organisation-approved browser if permitted. Record the application, browser version, error, and whether other users are affected. Do not install unapproved browser extensions.
