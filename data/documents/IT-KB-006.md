# Basic Laptop Performance Troubleshooting

Save your work and restart the laptop. Close unused applications and browser tabs. Check available disk space and use Task Manager or the system activity monitor to identify applications consuming unusually high CPU or memory. Confirm that operating-system updates are not waiting for a restart. Disconnect unnecessary peripherals and check whether performance improves. Raise a ticket if the device repeatedly freezes, overheats, or shuts down. Include the device name, when the issue began, affected applications, and error messages. Do not disable endpoint protection or open the laptop casing.
